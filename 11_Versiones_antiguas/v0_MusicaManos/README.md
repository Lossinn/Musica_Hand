# Hand Sing Kids! 🎵

![Logo de la aplicación](assets/images/mascot.png)

## Descripción del Proyecto

**Hand Sing Kids!** es una aplicación educativa e interactiva diseñada para que los niños aprendan las notas musicales básicas a través de gestos con las manos. Utiliza la cámara web para detectar y reconocer señas de mano específicas para cada nota musical (do, re, mi, etc.), creando una experiencia de aprendizaje divertida y práctica.

---

## Características Principales

-   **Reconocimiento de gestos en tiempo real:** Utiliza la librería MediaPipe para detectar y reconocer las manos del usuario.
-   **Calibración personalizada:** Permite a cada usuario calibrar el sistema con sus propias manos para una mayor precisión.
-   **Múltiples modos de juego:**
    -   **Tutorial:** Aprende las señas de las notas paso a paso.
    -   **Uso Libre:** Practica las notas a tu propio ritmo.
    -   **Minijuego (Notas Rítmicas):** Sigue una secuencia de notas al estilo de un juego de ritmo.
    -   **Juego de Reacción:** Imita las señas que aparecen en pantalla lo más rápido posible.
-   **Interfaz amigable y visual:** Diseñada con Pygame para una experiencia de usuario atractiva.

---

## Tecnologías Utilizadas

-   **Pygame:** Para la creación de la interfaz gráfica y la lógica del juego.
-   **OpenCV:** Para el manejo de la cámara web.
-   **MediaPipe:** Para la detección de manos y el reconocimiento de gestos.
-   **NumPy:** Para el manejo eficiente de datos numéricos.
