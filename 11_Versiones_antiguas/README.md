# 11_Versiones_antiguas

Snapshots de versiones previas que se conservan como referencia (§29, §44:
*no destruir el código que ya funciona*).

- Una subcarpeta por versión: `v0_prototipo_gestos/`, `v1_calibracion_manual/`…
- Incluir un `NOTAS.md` con: fecha, qué hacía, por qué se archivó, qué se rescató.
- El historial de git es la fuente principal; esto es para versiones que existieron
  antes del repositorio o para comparaciones rápidas sin cambiar de rama.
