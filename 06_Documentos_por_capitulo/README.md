# 06_Documentos_por_capitulo

Redacción del documento final, un directorio por capítulo.

| Capítulo | Contenido habitual                                                       |
|----------|------------------------------------------------------------------------|
| `Capitulo_1` | Planteamiento: necesidad, problema, objetivos, justificación, alcance. |
| `Capitulo_2` | Marco teórico y estado del arte (se nutre de `02_` y `08_`).           |
| `Capitulo_3` | Metodología y diseño del sistema: arquitectura (§24), modelo MILP (§12–14), ML (§16), RL (§17–21), gemelo digital (§22). |
| `Capitulo_4` | Resultados, indicadores (§32–33), validación (Fase 14) y conclusiones. |

Cada carpeta: `borrador.md`, `figuras/`, `notas.md`.
