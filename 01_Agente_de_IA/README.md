# 01_Agente_de_IA

Configuración, prompts y notas de trabajo del agente de IA que asiste el desarrollo
del proyecto (contexto, decisiones, convenciones acordadas).

Sugerencias de contenido:
- `contexto.md` — versión viva del contexto del proyecto.
- `decisiones.md` — bitácora de decisiones (fecha, decisión, motivo).
- `convenciones.md` — estilo de código, nombres, estructura de datos.
