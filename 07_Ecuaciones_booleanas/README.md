# 07_Ecuaciones_booleanas

Cadenas de búsqueda para la revisión de literatura, versionadas por base de datos.

| Carpeta   | Base                                                             |
|-----------|----------------------------------------------------------------|
| `BDC/`    | Bases de datos científicas de la biblioteca (BDC).             |
| `Scopus/` | Scopus.                                                        |
| `Pruebas/`| Iteraciones y ajustes de las ecuaciones (con nº de resultados).|

Registrar por cada ecuación: fecha, base, cadena exacta, filtros, nº de resultados,
observaciones. Conceptos base: *music education*, *adaptive learning*, *gesture
recognition*, *computer vision*, *reinforcement learning*, *digital twin*, *children*.
