# Proyecto Monte Carlo - Clorificador

## Cómo ejecutar

1. Abrir la carpeta en Visual Studio Code
2. Instalar extensiones:
   - Python
   - Jupyter
3. Instalar dependencias:
   pip install -r requirements.txt
4. Abrir montecarlo_clorificador.ipynb
5. Seleccionar el kernel de Python
6. Ejecutar celdas con Shift + Enter

Archivos generados:
- output/*.csv
- output/*.png
