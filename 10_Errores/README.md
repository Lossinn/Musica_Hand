# 10_Errores

Bitácora de errores y su resolución (respalda el principio §44: *probar cada cambio*).

Un archivo por incidente: `AAAA-MM-DD_titulo-corto.md`

```
## Síntoma
Qué se observó (mensaje, comportamiento).

## Contexto
Fase / módulo / comando / entorno.

## Causa
Diagnóstico raíz.

## Solución
Qué se cambió. Commit relacionado.

## Prevención
Test añadido / nota para no repetirlo.
```
