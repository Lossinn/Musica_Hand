# Musica

Experimentos de audio y teoría musical, aislados del prototipo.

Ideas de scripts:
- `notas.py` — frecuencias de DO–SI, reproducción con pygame.mixer.
- `mapeo_gesto_nota.py` — probar la correspondencia gesto → nota (§7).
- `secuencias.py` — generar secuencias para la dinámica "notas rítmicas".
- `feedback_audio.py` — sonidos de acierto / error / ánimo.

Los assets definitivos van a `03_Codigo/Prototipo/assets/{sounds,music}/`.
